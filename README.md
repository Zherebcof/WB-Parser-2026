# 🛒 Wildberries Parser Bot v1.0

Профессиональный Telegram-бот для парсинга товаров с Wildberries, аналитики цен и управления базой пользователей.

## 🎥 Демонстрация работы
[Смотреть видео обзор бота на YouTube](https://youtu.be/zTCmt1zuIKQ)

## 🚀 Функционал

### 👤 Для Пользователя:
- **Мгновенный поиск:** Парсинг выдачи Wildberries в реальном времени.
- **Excel-отчеты:** Генерация красивых таблиц с ценами, скидками и ссылками.
- **Фото-превью:** Бот присылает карточки товаров с фотографиями.
- **История:** Сохранение истории запросов.

### 👑 Для Администратора (CRM):
- **📊 Живая статистика:** Подсчет пользователей и запросов.
- **📢 Рассылка:** Массовая отправка сообщений всем пользователям бота.
- **📥 Выгрузка базы:** Скачивание списка клиентов в Excel.
- **🛡️ Защита:** Anti-Flood система (защита от спама и DDOS).
- **🚨 Логирование:** Уведомления об ошибках прямо в личку админу.

## 🛠 Технологии

- **Язык:** Python 3.10+
- **Фреймворк:** Aiogram 3 (AIO)
- **Парсинг:** Playwright (Headless Browser)
- **Данные:** Pandas + OpenPyXL (Excel Engine)
- **База данных:** SQLite + Aiosqlite
